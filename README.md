# Divine Portfolio

Personal site for Antony Divine Raj L — Product Manager building public-good tech at scale.

Built with Next.js 15 (App Router), Tailwind CSS, MDX, and Framer Motion. Deployed on Vercel.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Pushes to `main` auto-deploy on Vercel.
